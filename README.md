# Job Hunt Tracker - Product Designer Edition

## 🎯 Purpose
A smart, ethical, semi-automated job search system for Product Designers in India. Focuses on quality applications over quantity, direct outreach, and trackable metrics.

## 📚 Documentation
- **[Job Search Strategy](JOB_SEARCH_STRATEGY.md)** - Complete strategy guide
- **[Google Sheets Template](sheets_template/)** - Spreadsheet structure
- **[Email Templates](email_templates/)** - Customizable outreach templates
- **[Colab Notebooks](notebooks/)** - Automation helpers

## 🚀 Quick Start

### 1. Set Up Your Tracking System
1. Copy the Google Sheets template (link below)
2. Customize for your profile
3. Start adding target companies

### 2. Optimize Your Profile
- LinkedIn: Complete, keyword-optimized
- Portfolio: Case studies with metrics
- Resume: ATS-friendly, role-specific

### 3. Start Smart Job Hunting
- Research 3-5 jobs daily
- Apply to 5-10 quality positions weekly
- Direct outreach to 3-5 hiring managers weekly
- Track everything

## 📊 Expected Results
- **Response Rate:** 10-20% (vs 1-2% with Easy Apply)
- **Time Investment:** 1-2 hours/day
- **Timeline:** 4-8 weeks to offers (depends on market)

## ⚠️ What This System IS NOT
- ❌ Not an auto-apply bot (those get you banned)
- ❌ Not a LinkedIn scraper (violates ToS)
- ❌ Not a spam email tool (damages reputation)
- ✅ It's a smart tracking & personalization system

## 🛠️ Tech Stack
